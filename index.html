The Problem

AI agents communicate in flat text.
All the signal about how something was expressed gets lost.

Confidence
"likely 25-30%" — how confident, really?
Register
Is this precision or hedging?
Cognitive mode
Analytical? Embodied? Relational?
Intent
Informing? Warning? Seeking consensus?

The receiving agent re-infers everything from scratch. Wasted compute and lost fidelity. Paratext generates this metadata through competitive multilingual generation and delivers it as a JSON sidecar alongside every message.

How It Works

Competitive multilingual generation, not translation

01
Segment

Input text splits into cognitive clauses — one thought per clause, based on meaning boundaries rather than punctuation.

02
Generate

Each clause is independently generated in 6 languages in parallel. Not translated — natively generated. Each language activates different computational pathways.

03
Score

Every version is scored for naturalness (0.0–1.0). The language where the idea fits most naturally wins. Cognitive mode identified from the competition pattern.

04
Route

Two output paths: agent-to-agent delivers each clause in its winning language (the switch IS the metadata). Human-facing delivers back-translated version with annotations.

Key Insight

Different languages do not just rephrase — they deform reasoning trajectories. German compounds make precision relationships atomic. Spanish embodiment verbs surface physical reasoning. Japanese relational grammar reveals social-hierarchical thinking. The language that wins tells you how that thought naturally wants to be structured.

Integration

Wrap any agent message in three lines

paratext-envelope is middleware. It sits between agents and enriches every message with clause-level cognitive metadata. 

import { generateEnvelope } from 'paratext-envelope';

const envelope = await generateEnvelope(
  agentMessage,
  { context: 'risk-assessment' }
);

// envelope.clauses[0].winner       "german"
// envelope.clauses[0].confidence   0.91
// envelope.clauses[0].scores       { german: 0.91, ... }
// envelope.metadata.dominant_register
import { summarizeEnvelope } from 'paratext-envelope';

for (const clause of envelope.clauses) {
  if (clause.winner === 'french' && clause.confidence > 0.8) {
    // High-confidence uncertainty detected
    // Flag for human review
  }
}
